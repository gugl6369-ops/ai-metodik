CSS: управляй внешним видом

CSS задаёт цвет, размер, отступы, расположение и состояния элементов.

1. Базовые стили: margin, padding и box-sizing

У браузера есть встроенные стили: например, у body часто есть внешний отступ, а у заголовков — свои margin. Из-за этого макет может начинаться не с края и вести себя непредсказуемо. Поэтому в начале проекта задают контролируемую базу.

* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

html { scroll-behavior: smooth; }
body { font-family: system-ui, sans-serif; line-height: 1.5; }
01

margin: 0

Убирает внешние отступы по умолчанию. Затем ты задаёшь их там, где нужно, вместо борьбы с неожиданными промежутками.

02

padding: 0

Убирает внутренние отступы браузера, например у списков и кнопок. При необходимости добавляй свои.

03

box-sizing: border-box

Ширина включает padding и border. Так проще считать размеры и избегать переполнения контейнера.

Нюанс: это распространённая стартовая база, а не правило навсегда. Сброс не означает, что весь сайт должен остаться без отступов: возвращай нужные margin, padding и gap осознанно.

2. Селекторы и каскад

СелекторПримерЧто выбирает
По тегуp { ... }Все абзацы.
По классу.card { ... }Элементы с class="card".
По id#hero { ... }Элемент с id="hero"; id должен быть уникальным.
Вложенный.card p { ... }Абзацы внутри .card.
Прямой ребёнок.card > p { ... }Только непосредственные p-дети .card.
Состояниеa:hoverСсылка под указателем.
Атрибутinput[required]Поля, у которых есть required.

При конфликте правил учитываются важность, специфичность и порядок объявления. Избегай лишнего !important — лучше сделать селекторы понятнее.

3. Box model — коробочная модель

Коробка состоит из content → padding → border → margin. Меняй значения и сравнивай расчёт ширины.

4. Псевдоклассы и псевдоэлементы

Псевдокласс: состояние

:hover, :focus-visible, :checked, :first-child выбирают элемент по состоянию или положению.

.button:hover { transform: translateY(-2px); }
.button:focus-visible { outline: 3px solid orange; }

Псевдоэлемент: часть элемента

::before и ::after создают декоративные части без отдельного HTML-узла. Обычно им нужно свойство content.

Псевдоэлемент ::beforeПсевдоэлемент ::after
.sparkle-label::before { content: "✦"; }
.arrow-label::after { content: " →"; }
