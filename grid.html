Grid: строй сетки

Grid помогает собирать сетки карточек и крупные макеты, где важны и строки, и столбцы.

1. Контейнер Grid

Родитель получает display: grid. Колонки задают через grid-template-columns, промежутки — через gap. repeat() сокращает повторяющиеся значения.

.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 16px;
}

3. Основные свойства Grid

СвойствоНазначениеПример
grid-template-columnsРазмер и число колонок.repeat(3, 1fr)
grid-template-rowsРазмер строк.auto 1fr auto
gapРасстояние между ячейками.16px
minmax()Диапазон допустимых размеров.minmax(160px, 1fr)
repeat()Повторяет шаблон.repeat(3, 1fr)
grid-columnПоложение/растягивание по колонкам.1 / -1
place-itemsСокращение align-items + justify-items.center
Flexbox чаще выбирают для одной оси, Grid — для двухмерной сетки. Их нормально сочетать.
