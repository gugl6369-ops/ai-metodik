СТРУКТУРА И СМЫСЛ

HTML: каркас сайта

HTML описывает содержимое и смысл элементов. CSS отвечает за внешний вид, JavaScript — за поведение.

1. Базовая структура HTML5

Начинай документ с объявления типа, указывай язык и кодировку. viewport помогает странице корректно масштабироваться на телефонах.

<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Название страницы</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <header>Шапка сайта</header>
  <main><h1>Привет!</h1></main>
  <footer>Подвал</footer>
</body>
</html>
Важно: содержимое находится в body, метаданные — в head. На странице обычно один основной main.

2. Семантические теги можно вкладывать

Теги не являются отдельными коробками, которые запрещено сочетать. Вкладывай их по смыслу и соблюдай правила HTML.

header
nav Главная · Каталог · О нас
main
section: Популярное
article: Карточка 1article: Карточка 2article: Карточка 3
footer

Пример вложения

<header>
  <a href="/">Логотип</a>
  <nav aria-label="Основная">
    <a href="/">Главная</a>
  </nav>
</header>
<main>
  <section aria-labelledby="popular">
    <h2 id="popular">Популярное</h2>
    <article>Карточка товара</article>
    <article>Карточка новости</article>
  </section>
</main>
  • header может содержать логотип, заголовок и nav.
  • section группирует тему и обычно содержит заголовок; внутри могут быть article-карточки.
  • article подходит для самостоятельного материала: новости, поста, товара.
  • div — нейтральный контейнер, если специальный смысловой тег не нужен.

4. Атрибуты: что они делают

Атрибуты указываются в открывающем теге: <a href="/about" class="link">О нас</a>. Значения обычно заключают в кавычки.

id

Уникальный идентификатор на странице: якорь, связь с label или поиск элемента в JS.

id="team"

class

Объединяет элементы для CSS и JS. Несколько классов разделяют пробелом.

class="card featured"

href и src

href задаёт адрес ссылки или ресурса; src — источник изображения, скрипта или медиа.

src="photo.jpg"

alt

Текстовая альтернатива изображения. Для чисто декоративного изображения допустимо alt="".

alt="Городской парк"

type, name, value

В формах: тип поля, имя параметра и отправляемое значение.

type="email" name="email"

required, disabled

Требуют заполнения поля или отключают взаимодействие с элементом.

<input required>

target и rel

Определяют, где открыть ссылку и связь документов. Для target="_blank" уместно rel="noopener noreferrer".

target="_blank"

aria-*

Передают вспомогательным технологиям доступное имя или состояние. Не заменяют семантический HTML.

aria-label="Основная навигация"

data-*

Пользовательские данные для скриптов, например категория карточки.

data-category="media"

lang, title

lang задаёт язык фрагмента. title — дополнительная подсказка, не единственное объяснение.

<html lang="ru">

width, height

Задают размеры медиа и помогают браузеру зарезервировать место до загрузки.

width="640" height="360"

placeholder, min, max

Подсказка в поле и границы допустимого значения для подходящих типов input.

type="number" min="1" max="10"
Глобальные атрибуты: id, class, title, lang, hidden, tabindex доступны многим элементам. Специальные атрибуты работают только там, где предусмотрены стандартом.
