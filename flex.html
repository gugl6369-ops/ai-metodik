Flexbox: двигай элементы

Flexbox удобен для навигации, панелей инструментов, групп кнопок и карточек в одну линию.

1. Контейнер и элементы

Задай родителю display: flex. Его непосредственные дети станут flex-элементами. justify-content управляет главной осью, align-items — поперечной.

.container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

3. Основные свойства Flexbox

СвойствоНазначениеЗначения
displayВключает flex-модель.flex
flex-directionНаправление главной оси.row, column, reverse
justify-contentРаспределение по главной оси.center, space-between
align-itemsВыравнивание по поперечной оси.center, stretch
gapРасстояние между элементами.8px, 1rem
flex-wrapРазрешает перенос.nowrap, wrap
flexРост, сжатие и базовый размер.1, 0 0 200px
Если выравнивание не работает, проверь: flex-свойство должно быть задано родителю.
