ОТЛАДКА В БРАУЗЕРЕ

DevTools: смотри под капот

Инструменты разработчика помогают понять, какой HTML создал страницу, какие CSS-правила применились и почему макет выглядит не так, как ожидалось.

1. Как открыть DevTools

Windows / LinuxF12или Ctrl + Shift + I
macOS⌘ + ⌥ + Iили меню браузера → разработчик
Выбрать элементCtrl + Shift + Cна macOS: ⌘ + Shift + C

Открой сайт в Chrome, Edge или Firefox. Ищи вкладки Elements/Inspector, Styles/Rules, Console и Network. Названия немного различаются между браузерами.

2. Elements: найди HTML-элемент

Нажми инструмент выбора элемента (иконка курсора), затем кликни по заголовку или карточке на странице. В Elements подсветится соответствующий узел DOM.

  1. Выбери элемент курсором выбора.
  2. В DOM раскрывай родительские и дочерние элементы.
  3. Наведи на узел — браузер подсветит его область на странице.
  4. Двойной клик по тексту или атрибуту позволяет временно его изменить.

3. Styles и Box Model: проверь CSS

  • Styles: показывает применённые правила и источник CSS.
  • Зачёркнутое свойство: обычно проиграло другому правилу из-за каскада или специфичности.
  • Галочка у свойства: выключи правило и посмотри, что изменится.
  • Computed: итоговые вычисленные значения CSS.
  • Box Model: размеры content, padding, border и margin.
Помни: изменения в DevTools обычно временные. Перенеси нужное правило в CSS-файл, чтобы сохранить его.

4. Проверь адаптивность

Нажми кнопку устройства (Toggle device toolbar) или Ctrl + Shift + M в Chromium. Выбери устройство или введи ширину экрана вручную.

  1. Проверь ширину 320–390 px, планшет и широкий экран.
  2. Убедись, что нет случайной горизонтальной прокрутки.
  3. Проверь меню, карточки, изображения, формы и текст.
  4. Меняй ширину постепенно: ошибки бывают на промежуточных размерах.

5. Console: найди ошибки JavaScript

Console показывает ошибки и предупреждения. Красная ошибка часто содержит файл и номер строки — кликни по ссылке, чтобы перейти к коду.

Console ×

✖ Uncaught TypeError: Cannot read properties of null

at app.js:24

Подсказка: скрипт может искать элемент, которого нет на этой странице.

Порядок отладки

  1. Повтори проблему и зафиксируй ожидаемый и реальный результат.
  2. Проверь элемент в Elements.
  3. Посмотри в Styles, какие правила победили.
  4. Открой Console и исправь ошибки, если они есть.
  5. Проверь результат на нескольких ширинах.
